# NadheWedd Landing Kit

Everything the new landing-page project needs, exported from the NadheWedd
invitation repo on 2026-10-17.

How to use:

1. Create the new project folder (e.g. `nadhewedd-landing/`) and copy this whole
   `nadhewedd-landing-kit/` folder into it.
2. Open the new project in Claude Code and paste the contents of
   `PROMPT-LANDING-PAGE.md`, or tell it to read that file.
3. Claude will report on the setup and propose a plan first. Approve it before
   it builds.

Contents: `PRODUCT-FACTS.md` (what is real), `design/brand-tokens.css` (colors,
fonts, surfaces), `assets/` (florals, ornaments, illustrations, icons), and
`screenshots/` (15 real UI screenshots with fictional demo guests).

Before going public:

- Confirm that the floral/ornament artwork may be used commercially.
- Decide the NadheWedd logo, domain and hosting (commercial plan).
- Get Naubill & Dhea's OK for showing their illustration in "Implementasi Perdana".
